موقع مُشفّر

1) لتعديل الرسالة: افتح index.html بمحرر نصوص وابحث عن:
const MESSAGE = `
واستبدل الكلام بين علامتي ` بالنص المطلوب. لا تحذف علامتي `.
2) لرفع الموقع: ارفع ملف index.html إلى المجلد العام (public_html) في الاستضافة، أو اسحبه إلى خدمة استضافة مواقع ثابتة.
3) الموقع يعمل محلياً أيضاً بالنقر مرتين على index.html.

تنبيه مهم: هذا نموذج واجهة أمامية فقط. مفتاح الدخول ورقم العملية موجودان في كود الصفحة ويمكن الاطلاع عليهما عبر أدوات المتصفح. ليس مناسباً لحماية بيانات حساسة أو لإثبات حدوث حذف فعلي للبيانات. رسالة الحذف عرض توضيحي ولا تحذف أي بيانات بالفعل.
